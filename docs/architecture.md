# Arquitectura

## Filosofía

Toda la aplicación gira alrededor de un único archivo:

life_profile.json

Ese archivo representa completamente al usuario.

La interfaz únicamente representa ese estado.

No existen datos quemados dentro del código.

---

## Principios

- Single Source of Truth
- Offline First
- Configuración sobre código
- Modularidad
- Evolución continua
