# LifeOS V1

> Mi sistema operativo personal.

LifeOS V1 es una aplicación web desarrollada como herramienta personal para organizar mi vida mientras construyo la versión profesional en Flutter.

Esta versión no pretende ser un producto comercial.

Su objetivo es validar el modelo de datos, mejorar mi productividad y servir como laboratorio para la futura arquitectura.

---

# Objetivos

- Centralizar toda mi información personal.
- Tener una única fuente de verdad (`life_profile.json`).
- Poder modificar mi vida sin recompilar la aplicación.
- Aprender arquitectura de software mientras desarrollo.
- Preparar la migración hacia Flutter.

---

# Tecnologías

- HTML
- CSS
- JavaScript
- JSON
- LocalStorage

---

# Filosofía

Toda la aplicación gira alrededor de un único archivo:

life_profile.json

La interfaz solamente representa esos datos.

No existen datos quemados dentro del código.
